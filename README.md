# San Francisco City Employee Salary Prediction

## About
This project implements machine learning to predict the base salaries of San Francisco city employees. The XGBoost model is trained on over 1 million employee records.

## Technologies Used
- Python
- XGBoost
- Streamlit
- Pandas, NumPy, Scikit-learn

## Model Performance
- R²: 0.95
- Dataset: 1,078,190 rows

## Features
- Real-time salary prediction with employee information
- Automatic employee ID generation
- Saving prediction results to CSV
- Web interface (Streamlit)

## How to Run
pip install streamlit xgboost pandas numpy scikit-learn

streamlit run app.py

## Data Source
San Francisco Controller's Office - Employee Compensation Dataset
